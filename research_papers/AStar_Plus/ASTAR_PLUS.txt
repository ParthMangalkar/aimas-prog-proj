Keywords:                                                 The A* algorithm is widely recognized as one of the most effective solutions for grid-based path planning.
Path planning                                             However, when it comes to complex obstacle fields, its performance significantly degrades on large-scale grid
A* algorithm                                              maps exceeding 10,000 × 10,000 in size, where computational complexity and memory usage increase drasti­
Grid map
                                                          cally. To address these challenges and accelerate the path planning tasks, we propose the A*-plus algorithm,
Algorithm optimization
                                                          which introduces a node compression strategy by aggregating 2 × 2 grid cells into single nodes, thereby sub­
                                                          stantially reducing the search space. Derived entirely from the A* framework, A*-plus is fully compatible with
                                                          existing optimization techniques designed for A*, such as priority queues and heuristic functions. Experimental
                                                          evaluations on 10,000 × 10,000 grid maps with varying obstacle densities show that A*-plus achieves a 93 %
                                                          reduction in search time and a 60 % decrease in memory usage compared to the traditional A* algorithm,
                                                          without compromising path optimality. These results demonstrate the effectiveness of A*-plus in enabling real-
                                                          time path planning in expansive grid environments.

                                                                                    3.2.6. Path backtracking method
                                                                                        In the standard A* algorithm, the path is reconstructed by recording
                                                                                    the parent of each visited node and backtracking from the goal node to
                                                                                    the start node once the search is complete. This approach yields an exact
                                                                                    path through individual grid cells. However, in the A*-plus algorithm,
                                                                                    the initial backtracking process only yields a coarse path between
                                                                                    compressed nodes. To achieve a precise path at the grid-cell level, an
                                                                                    enhanced backtracking mechanism is required.
                                                                                        As illustrated in Fig. 6, consider the scenario of moving horizontally
                                                                                    from one compressed node to the next. In the straightforward case
                                                                                    shown in Fig. 6(a), if the transition from the current node to the adjacent
                                                                                    one is unobstructed, the algorithm directly traverses two grid cells to the
                                                                                    right. In contrast, Fig. 6(b) depicts a case where the direct path is
                                                                                    blocked. Here, the algorithm determines whether the current position
                                                                                    lies in the upper or lower part of the compressed block. If in the upper
                                                                                    section, it first moves one cell downward, then proceeds rightward. If in
                                                                                    the lower section, it first moves upward before continuing to the right.
